# Legacy audio v1 documentation

This directory preserves the former PICO-8-compatible software-synthesis and
Direct Sound documentation as historical engineering evidence.

It is not the current Mtile audio product contract. Native GBA audio v2
replaces its PICO instruments, effects, four interchangeable logical channels,
asset formats, editor model, and conformance gates with direct support for the
GBA's four PSG channels and two Direct Sound FIFO buses.

Relative links and commands inside these snapshots reflect their original
location and may point at examples or tools that will also be archived during
the v2 migration.

The captured measurements remain useful for understanding the current code
until the v2 implementation replaces it. They must not be quoted as v2
performance or completion evidence.
