# Getting help

Start with the [setup guide](docs/getting-started.md),
[reference](docs/reference.md), and [examples](examples/README.md).
For sound-specific problems, use [audio troubleshooting](docs/audio/troubleshooting.md).

If you still need help, search the repository's existing issues, then open a
**Question / help** issue. Include your operating system, Go and TinyGo
versions, the exact command or editor action, and the full error text. A small
project is usually more useful than a screenshot of an error.

Use **Bug report** for behavior that contradicts the documentation, and
**Feature request** for a workflow Mtile does not yet support. For performance
reports, include the selected renderer, `stat(1)`/frame-cycle measurements,
and a repeatable scene or input sequence. Desktop CPU percentage alone does
not measure the cartridge's GBA frame budget.

Only share source and assets you have permission to distribute. Remove local
credentials and personal data from logs and reproductions. Use the
[security reporting policy](SECURITY.md) for vulnerabilities.

Support is community-based, with no guaranteed response time. Focused reports
and documentation fixes help everyone who encounters the same problem.
