# Research projects

The repository includes the font experiment and engineering notes, measurements,
and test tools for historical renderer experiments.

| Project | Status |
| --- | --- |
| [font-typography](font-typography/README.md) | Isolated size/typography proposals, real ROM previews, before/after cycle/memory evidence; production font contract unchanged |
| [celeste-mode0](celeste-mode0/README.md) | Mode 0 benchmark notes and local verification tools |
| [celeste-parallax](celeste-parallax/README.md) | Experimental tile-canvas comparison notes |

The Celeste benchmarks used local adaptations of a third-party cartridge.
Reproducing the gameplay runs requires a separately supplied port, including
its Lua source, graphics, maps and audio. The Loop port was also a local input.
The maintained image-import regression uses Lantern Rooms and Testio.
