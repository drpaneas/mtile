# Native PCM samples

> **Legacy audio v1 fixture.** This project remains runnable while native-GBA
> audio v2 is developed, but its mixed profile and API are not the v2 Direct
> Sound contract. See the
> [archived v1 documentation](../../docs/audio/legacy/v1/).

This project exercises the version-1 WAV pipeline and the native `sample()`
API at the supported 16,384 Hz mono target rate while two authored synth
channels play through `music()`. It is the shipped example of the measured
two-synth-plus-one-PCM mixed safety profile.

- O plays a normalized, silence-trimmed one-shot impact using manifest volume
  and priority.
- X starts a looping engine sample.
- Up plays the impact with explicit volume `96` and priority `200`.
- Down calls `sample(-1)` to stop native PCM voices without stopping synth or
  music voices.
- Start restarts the two-channel pattern with a 500 ms fade-in.
- Select fades out only the music-owned synth voices over 500 ms.

Open the project with `mtile edit examples/audio-samples`; tabs 3 and 4 show
the authored synth SFX and looping pattern, while tab 5 compares source and
exact target-mixer sample previews. Drop additional PCM WAV files anywhere on
the editor window to import them.

The checked-in WAV files are deterministically generated by
`go run ./scripts/generate_samples.go` from this directory. The build retains
the WAV sources and emits only converted signed 8-bit PCM into cartridge ROM.

Build with:

```sh
mtile build examples/audio-samples
```
